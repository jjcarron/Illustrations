# Illustrations

Ce dépôt contient une collection de programmes Python pour créer des illustrations et des visualisations destinées à la documentation.

## Description

Ce projet regroupe divers scripts et programmes Python qui génèrent des illustrations graphiques, des diagrammes, et d'autres contenus visuels utiles pour enrichir la documentation technique.

## Prérequis

- Python 3.6 ou supérieur
- pip (gestionnaire de paquets Python)

## Installation

1. Cloner ce dépôt :
```bash
git clone https://github.com/jjcarron/Illustrations.git
cd Illustrations
```

2. Créer un environnement virtuel (recommandé) :
```bash
python -m venv venv
source venv/bin/activate  # Sur Linux/Mac
# ou
venv\Scripts\activate  # Sur Windows
```

3. Installer les dépendances nécessaires :
```bash
pip install -r requirements.txt
```

## Utilisation

Chaque programme d'illustration est généralement un script Python autonome. Pour exécuter un script :

```bash
python nom_du_script.py
```

Les illustrations générées seront sauvegardées dans le répertoire de sortie approprié (généralement le même dossier ou un dossier `output/`).

## Structure du projet

```
Illustrations/
├── README.md           # Ce fichier
├── .gitignore         # Fichiers à ignorer par git
├── requirements.txt   # Dépendances Python (à créer selon besoins)
└── [scripts]          # Scripts Python d'illustration
```
